この資料を終えたらできること

3つのツールがすべてPCにインストールされ、実際の業務でAIに指示を出して作業を自動化できるようになります。

1

🐙 GitHub アカウント作成

まず最初にGitHubアカウントを作ります（所要時間：約5分）

📝
GitHubとは？

ファイルやフォルダをインターネット上に保存できるサービスです。「誰がいつどこを変更したか」の履歴が自動で残るので、チームで安全に作業できます。

📝

STEP 1 ｜ アカウントを作成する

github.com からサインアップ

1
ブラウザで GitHub を開く

ブラウザ（ChromeやSafari）で github.com にアクセスします。

2
「Sign up」をクリック

画面右上の緑色の「Sign up」ボタンをクリックします。

3
メールアドレスを入力

会社のメールアドレス（@runbird.net）を入力し、「Continue」をクリックします。

4
パスワードを設定

英数字と記号を含む、8文字以上のパスワードを設定します。後で使うのでメモしておきましょう。

5
ユーザー名を決める

半角英数字とハイフンのみ使えます。例：runbird-tanaka（会社名＋名前）のような形がおすすめです。

6
メール認証

登録したメールアドレスに確認コードが届きます。コードを入力して認証を完了させます。

✅
完了の確認

github.com にアクセスして、自分のアイコン（右上）が表示されていればアカウント作成完了です。

🖥️

STEP 2 ｜ GitHub Desktop をインストールする

コマンド不要でGitHubを使えるアプリ（初心者向け）

💡
GitHub Desktop とは？

GitHubを画面上のボタン操作だけで使えるアプリです。難しいコマンド入力が不要で、初心者でもファイルのアップロード・ダウンロードが簡単にできます。

1
GitHub Desktop をダウンロード

desktop.github.com にアクセスし、「Download for Mac」または「Download for Windows」をクリックします。

2
インストール

Macの場合はダウンロードした .dmg ファイルを開き、アイコンをアプリケーションフォルダにドラッグします。Windowsの場合はインストーラーを実行します。

3
GitHubアカウントでサインイン

アプリを起動して「Sign in to GitHub.com」をクリックし、先ほど作成したアカウントでログインします。

4
自分の名前とメールを設定

名前とメールアドレスの入力を求められたら、実名とメールアドレスを入力します。これは変更履歴に表示される名前です。

2

🖱️ Cursor インストールと設定

AIと一緒に使えるエディタをセットアップする（所要時間：約10分）

📝
Cursorとは？

メモ帳を大幅に進化させたソフトウェアです。ファイルを開いて確認したり、AIに質問しながら編集したりできます。コードが書けない人でも、AIが手助けしてくれます。

⬇️

STEP 1 ｜ Cursor をインストールする

cursor.com からダウンロード

1
公式サイトへアクセス

ブラウザで cursor.com にアクセスします。

2
「Download」をクリック

トップページの「Download」ボタンをクリックします。お使いのOS（MacまたはWindows）に合わせたファイルが自動でダウンロードされます。

3
インストール

Mac：ダウンロードされた .dmg ファイルを開き、Cursor アイコンを「アプリケーション」フォルダにドラッグします。
Windows：ダウンロードされた .exe ファイルを開き、画面の指示に従います。

4
Cursor を起動する

アプリケーションフォルダ（Mac）またはデスクトップ（Windows）の Cursor アイコンをダブルクリックします。

⚙️

STEP 2 ｜ 初期設定をする

初回起動時の設定ウィザード

1
言語設定（任意）

初回起動時に言語を聞かれる場合があります。日本語表示は対応が限られるため、English のまま進めて問題ありません。

2
アカウント作成・ログイン

「Sign Up」または「Log In」を選択し、GitHubアカウントでログイン（「Continue with GitHub」）するのが最も簡単です。

3
プランの選択

「Hobby（無料）」プランで問題ありません。クレジットカードは不要です。

4
セットアップ完了

「Open Cursor」ボタンをクリックすると、エディタ画面が開きます。

🖼️

STEP 3 ｜ 画面の見方を覚える

どこに何があるかを把握する

エリア 位置 用途
サイドバー 左側 フォルダ・ファイルの一覧が表示される
エディタ画面 中央 ファイルの内容が表示・編集できる
AIチャット 右側 / 下部 AIに質問・指示ができる（Ctrl+Lで開く）
ターミナル 下部 コマンドを入力する黒い画面（後述）
💡
フォルダを開く方法

メニューの「File → Open Folder」または画面中央の「Open Folder」をクリックして、作業したいフォルダを選択します。

3

🤖 Claude Code インストールと設定

AIに業務を自動化させるツールをセットアップする（所要時間：約15分）

📝
Claude Code とは？

Anthropic社が開発した最先端のAIツールです。日本語でお願いするだけで、ファイルの作成・データ整理・投稿文の作成など、様々な作業を自動でやってくれます。

⚡

STEP 1 ｜ Node.js をインストールする（前提ソフト）

Claude Code を動かすために必要なソフトウェア

⚠️
なぜ必要？

Claude Code を動かすには「Node.js」というソフトが必要です。エンジンのようなもので、インストールするだけで普段は意識する必要はありません。

1
公式サイトへアクセス

ブラウザで nodejs.org にアクセスします。

2
「LTS」バージョンをダウンロード

「LTS（長期サポート版）」と書かれた緑色のボタンをクリックしてダウンロードします。

3
インストール

ダウンロードしたファイルを開き、「Continue」「Next」を押して進めます。すべてデフォルト設定のままでOKです。

4
インストールを確認する

ターミナル（Macなら「ターミナル」アプリ、Windowsなら「コマンドプロンプト」）を開いて、以下を入力します。

確認コマンド
node --version

「v20.x.x」のようなバージョン番号が表示されれば成功です。

🤖

STEP 2 ｜ Claude Code をインストールする

ターミナルでコマンドを実行してインストール

💡
ターミナルを開く方法

Mac：「アプリケーション → ユーティリティ → ターミナル」または Spotlight（⌘+スペース）で「terminal」と入力
Windows：スタートメニューで「cmd」または「PowerShell」と検索
Cursor内：メニューの「Terminal → New Terminal」でも開けます

1
ターミナルを開く

上記の方法でターミナル（黒い画面）を開きます。

2
インストールコマンドを実行

以下のコマンドをコピーして、ターミナルに貼り付けてEnterキーを押します。

インストールコマンド
npm install -g @anthropic-ai/claude-code

しばらく待つと「added XXX packages」のようなメッセージが表示されます。

3
インストール確認

以下のコマンドで正しくインストールされたか確認します。

確認コマンド
claude --version

バージョン番号が表示されれば成功です。

🔑

STEP 3 ｜ Claude Code にログインする

Anthropicアカウントと紐付けしてAIを有効化

1
Claude Code を起動する

ターミナルで以下のコマンドを入力します。

起動コマンド
claude
2
認証方法を選ぶ

「Login」の選択肢が表示されます。「Continue with Claude.ai」を選択します（Anthropicアカウントでログイン）。

3
ブラウザで認証

ブラウザが自動で開き、claude.ai のログイン画面が表示されます。会社から案内されたアカウントでログインします。

4
ターミナルに戻る

ブラウザでの認証が完了すると、ターミナルに「Logged in」のメッセージが表示されます。

✅
ログイン確認方法

ターミナルで claude と入力してEnterキーを押したとき、「>」のようなプロンプトが表示されてAIと会話できる状態になれば完了です。

💬

STEP 4 ｜ Claude Code の基本操作

AIへの指示の出し方

1
作業フォルダに移動してから起動する

必ず作業したいフォルダに移動してから Claude Code を起動します。

フォルダ移動→起動（Macの例）
cd ~/Documents/AI/CURSOR
claude
2
日本語でお願いするだけ

Claude Code が起動したら、やりたいことを日本語で入力するだけです。

例：日本語で指示
> 今日の日付でフォルダを作って
その中にレポートのテンプレートを作って
3
スキルコマンドを実行する

「/」から始まるコマンドで、よく使う作業を一発で実行できます。

よく使うコマンド例
/おはよう　← 朝の作業開始
/おつかれ　← 夕方の作業終了
4
終了するには

「/exit」と入力するか、Ctrl + C を押します。

終了コマンド
/exit
4

📋 日常の作業フロー

毎日の業務での3つのツールの使い方

🌅

朝：作業開始のルーティン

毎朝最初に行う手順

1
Cursor を開く

Cursor を起動して、作業フォルダ（例：AI/CURSOR）を開きます。

2
ターミナルで Claude Code を起動

Cursor 内のターミナル（メニュー → Terminal → New Terminal）で Claude Code を起動します。

朝のコマンド
claude

> /おはよう
3
最新データの取得が自動で行われる

「/おはよう」コマンドを実行すると、GitHubから最新のデータが自動で取得されます。

🌆

夕方：作業終了のルーティン

業務終了前に必ず行う手順

1
Claude Code で終了コマンドを実行

作業が終わったら、ターミナルの Claude Code で以下を実行します。

夕方のコマンド
> /おつかれ
2
自動でGitHubへ保存

今日の作業内容が自動でGitHubにアップロード（プッシュ）されます。これでデータが安全に保存されます。

3
GitHub Desktop で確認（任意）

GitHub Desktop を開くと、今日の変更内容が一覧で確認できます。

⚠️
「/おつかれ」を忘れずに！

退勤前に必ず「/おつかれ」を実行してください。実行しないと当日の作業がGitHubに保存されず、データが失われる可能性があります。

💬

AIに仕事をお願いするコツ

Claude Code を最大限活用するための指示の出し方

やりたいこと Claude Code への指示例
ファイルを作りたい 「〇〇のフォルダに△△というファイルを作って」
内容を確認したい 「〇〇のファイルの内容を教えて」
文章を作りたい 「〇〇向けのMEO投稿文を作って。店舗は△△」
作業の結果を確認したい 「今日何をしたか教えて」
エラーがわからない 「エラーが出た。〇〇と表示されているんだけど原因は？」
💡
指示は「5W1H」で具体的に

「だれに・何を・どこに・いつ・なぜ・どのように」を明確にするほど、AIの回答精度が上がります。曖昧な指示より具体的な指示のほうがうまくいきます。

❓ よくある質問・トラブル対処

困ったときの対処法

🛠️

トラブルシューティング

⚠️
Q. 「command not found: claude」と表示される

Node.js のインストールが正しくできていない可能性があります。Node.js を再インストールした後、npm install -g @anthropic-ai/claude-code を再実行してください。

⚠️
Q. Claude Code が「認証エラー」になる

ターミナルで claude を起動し、再度ログイン手順（STEP 3）を実行してください。ブラウザで claude.ai にログインできているか確認してください。

⚠️
Q. GitHubにアップロードできない

GitHub Desktop で「Repository → Pull」（最新データを取得）してから再度試してください。コンフリクト（衝突）が発生している場合は上長に相談してください。

⚠️
Q. Cursor が重い・フリーズする

一度 Cursor を完全に終了して再起動してください。それでも改善しない場合は、Cursor のキャッシュをクリアするか再インストールを試みてください。

💡
Q. AIが英語で回答してくる

指示の最初に「日本語で答えて」と一言追加するか、「Please respond in Japanese.」と入力してください。または指示を日本語で書けば日本語で返答されます。

💡
Q. どこまでAIに頼んでいい？

基本的に何でも頼んでOKです。ただし、パスワードや個人情報などの機密情報はAIに入力しないようにしてください。判断に迷ったら上長に確認してください。
